# NOVA Client

A performance-focused Eaglercraft 1.8 client.

## Vision

NOVA is built around a clean, lightweight client core with an emphasis on performance, customization, and PvP responsiveness.

### Planned modules

- FPS Booster — client-side rendering and update optimizations
- Crystal Optimizer — efficient crystal entity/render processing
- Fast Crystal — responsive client-side crystal interaction and targeting
- Network Optimizer — efficient client networking and accurate latency display
- NOVA HUD — FPS, ping, CPS, coordinates, and keystrokes
- NOVA ClickGUI — clean modular settings interface

> NOVA does not attempt to bypass server-side rules, limits, or anti-cheat systems.

## Project status

Early development. The repository currently contains the NOVA project scaffold and documentation; the Eaglercraft base will be integrated before the first playable build.
